# LogSentinel public showcase

This directory is a static, privacy-safe project presentation for Vercel. Its replay uses only local, redacted illustrative fixtures; it does not call an API, accept logs, load a model, or make performance claims.

Preview it from the repository root:

```bash
python -m http.server 4173 --directory showcase
```

Deploy only this directory. The complete Streamlit research lab is run separately from the Python project and is not embedded here.
